# テキストからのデッキ移行

画面上部の「インポート」から、元サイトのレシピタブで「テキストデータをコピー」した内容を貼り付けられます。「内容を確認する」で枚数を確認し、「1件をインポート」でマイデッキに追加します。デッキ名は任意です。既存の保存済みデッキと編集中のレシピは保持されます。

## 対応形式

- [元サイト](https://sweetpotato.github.io/ijinden-deck-builder/)の2列TSV。メインデッキ・サイドデッキの見出しを含む1デッキ分。
- このデッキ帳の「テキストデータをコピー」で出力した、カードID付きのテキスト。
- JSONファイルのインポートも、同じダイアログの「JSONファイルを選ぶ」から利用できます。

元サイトの「第5弾」「スターター」「PSR」等の注記も含めて照合します。注記のない同名カードに複数候補がある場合は、収録版を選択します。不明なカードや枚数の不一致がある場合は、全体をエラーにして、カードを勝手に除外しません。上限は40万文字、合計1000枚、デッキ名200文字です。

## カード名対応表の更新

`data/legacy-deck-text-names.ts` は元サイトの公開カードデータの表示名と、このアプリのカードIDの対応表です。両サイトが参照する公式画像URLの一致により生成しています。参照元のコミットは生成ファイル先頭に記録されます。

```sh
python scripts/build-legacy-text-map.py
node node_modules/oxfmt/bin/oxfmt --write data/legacy-deck-text-names.ts
node --experimental-strip-types --test tests/deck-text-import.test.mjs
```

生成時に未対応の画像URLが見つかった場合は、先にカード一覧を更新してください。取り込み処理はブラウザ内で完結し、貼り付けたデッキデータを外部へ送信しません。
